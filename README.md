# qwe studio

Сайт студии qwe studio: сайты, интернет-магазины, веб и мобильные приложения, брендинг.

## Публикация на GitHub Pages
1. Загрузите в репозиторий всё содержимое этой папки так, чтобы `index.html` лежал в корне.
2. Откройте Settings → Pages → Build and deployment: Source «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

## Что внутри
- `index.html` — главная страница студии.
- `img/` — картинки для портфолио и первого экрана.
- `works/` — пять живых концептов (Ступень, СОРТ магазин, СОРТ приложение, СОРТ брендбук, Слот). Открываются по адресам вида `.../works/stupen/`.
- `404.html` — страница для несуществующих адресов.
