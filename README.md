# qwe studio

Сайт студии qwe studio: сайты, интернет-магазины, веб и мобильные приложения, брендинг. Светлая версия.

## Как обновить сайт на GitHub Pages
1. Откройте репозиторий `qweqwasdd/design-studio`.
2. Загрузите содержимое этой папки с заменой файлов, чтобы `index.html` лежал в корне репозитория.
   Через сайт GitHub: Add file → Upload files, перетащите все файлы и папки, затем Commit changes.
3. Через 1-2 минуты обновление появится по адресу https://qweqwasdd.github.io/design-studio/
   Если видите старую версию, обновите страницу с очисткой кэша: Ctrl + F5.

## Что внутри
- `index.html` главная страница.
- `img/` картинки работ и превью для соцсетей (`og.jpg`).
- `works/` кейс SmartGlobal Systems и пять живых проектов: Ступень, магазин СОРТ, приложение СОРТ, брендбук СОРТ, Слот.
- `404.html` страница для несуществующих адресов. Ссылка «На главную» ведёт на `/design-studio/`.
  Если переименуете репозиторий, поменяйте этот путь в `404.html`.
- `.nojekyll` отключает обработку Jekyll, чтобы GitHub отдавал файлы как есть.
