# qwe studio

Сайт-портфолио: дизайн и разработка сайтов, интернет-магазинов, веб- и мобильных приложений, фирменный стиль.

**Сайт:** https://qweqwasdd.github.io/qwedesign/

## Работы

- **Глэмпинг «Аура»** — сайт с бронированием: выбор домика, расчёт суммы и предоплаты, смена сезонов на первом экране.
- **ORLO** — промо-сайт и веб-консоль платформы ИИ-вычислений: живой график нагрузки, управление узлами кластеров, терминал с командами.
- **«Зилант»** — сайт аренды премиальных автомобилей в Казани: бесшовное видео с BMW M5 на первом экране, автопарк с превью, бронирование с расчётом цены.
- **Клиника ÉCLAT** — сайт клиники эстетической медицины с онлайн-записью в формате чата: процедура, свободные окна, подтверждение заявки.
- **SmartGlobal Systems** — коммерческий сайт для компании из Казахстана: анализ ниши, прототип, интерфейс для компьютера и телефона.
- **Кабинет подологии «Ступень»** — лендинг с интерактивной картой стопы, прайсом и онлайн-записью.

Каждая работа открывается в браузере как живой сайт, а не как картинка.

## Как сделано

- Вёрстка и логика на HTML, CSS и чистом JavaScript, без тяжёлых фреймворков.
- Адаптив под телефон, управление с клавиатуры, учёт настройки «уменьшить движение».
- Шрифты хранятся на самом сайте, картинки сжаты в WebP с облегчёнными версиями для телефонов.
